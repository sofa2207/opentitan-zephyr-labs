# OpenTitan × Zephyr RTOS

**Лабораторные и практические работы по запуску и исследованию Zephyr на модели OpenTitan.**

Подготовка окружения, команды сборки, результаты запусков и разбор возникших ошибок. Каждая работа хранится в собственной папке вместе с иллюстрациями и материалами.

[Начать с подготовки окружения](labs/01-environment/README.md) · [Каталог работ](labs/README.md) · [Добавить новую работу](docs/adding-a-lab.md)

## Практические работы

| № | Работа | Содержание | Результат по отчёту |

## Окружение первой работы

| Компонент | Версия / конфигурация |
| --- | --- |
| Ubuntu | 24.04 |
| OpenTitan | `earlgrey_1.0.0` |
| Verilator | 4.210 |
| Zephyr RTOS | 3.7.0 |
| Zephyr SDK | 0.16.8 |

Версии приведены из исходного отчёта. При повторении используйте совместимый набор инструментов и учитывайте [замечания к воспроизведению](labs/01-environment/README.md#паспорт-работы).

## Первый результат

В исходном отчёте зафиксирован вывод модели:

```text
*** Booting Zephyr OS build v3.7.0 ***
Hello World! opentitan_earlgrey/opentitan
```

В [первой работе](labs/01-environment/README.md) сохранены команды, пояснения и 30 скриншотов — от настройки системы до вывода UART.

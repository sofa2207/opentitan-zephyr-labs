# Как добавить практическую работу

[Главная](../README.md) · [Каталог работ](../labs/README.md)

## Названия и структура

Используйте последовательную нумерацию и короткие имена латиницей: `01-environment`, `02-short-name`. Не меняйте номера уже опубликованных работ без необходимости: на них могут ссылаться другие материалы.

В папке каждой работы должен быть `README.md`. GitHub показывает его при открытии папки.

| Файл или папка внутри работы | Когда нужен |
| --- | --- |
| `README.md` | Всегда: цель, ход работы, команды, проверки, вывод |
| `images/` | Есть скриншоты или иллюстрации |
| `src/` | Есть собственный исходный код |
| `results/` | Есть отобранные журналы, измерения и результаты |

## Порядок добавления

1. Создайте папку `labs/02-short-name/` с названием следующей работы.
2. Скопируйте туда [шаблон](../templates/lab/README.md) как `README.md`.
3. Заполните отчёт: команды, версии, рабочие папки, ожидаемый и фактический результат.
4. Добавьте иллюстрации в `images/` рядом с отчётом. Используйте относительные ссылки, например `![Результат сборки](images/01-build.png)`.
5. При наличии добавьте собственные исходники и результаты. Не копируйте целиком OpenTitan, Zephyr и SDK.
6. Добавьте строку с работой в таблицы [главной страницы](../README.md) и [каталога](../labs/README.md).
7. Проверьте отображение Markdown, ссылки и изображения на GitHub.

В журнале результата оставляйте фактический вывод. Невыполненные проверки отмечайте явно; не заменяйте их ожидаемым результатом.

## Первая загрузка через GitHub

1. Распакуйте подготовленный архив на компьютере.
2. Откройте свой репозиторий `sofa2207/opentitan-zephyr-labs`, вкладку **Code**.
3. Выберите **Add file → Upload files**.
4. Перетащите содержимое папки `opentitan-zephyr-labs`: `README.md` и каталоги `labs`, `docs`, `templates`. Сам ZIP загружать не нужно. Если менеджер файлов показывает `.gitignore`, добавьте и его.
5. Если `.gitignore` не отображается, создайте его через **Add file → Create new file** и скопируйте содержимое из распакованного архива.
6. Замените стартовый `README.md` подготовленным. Сообщение коммита: `Оформлена первая работа: окружение OpenTitan и Zephyr`.
7. Сохраните изменения в `main`, затем откройте главную страницу и первую работу.

Перетаскивайте содержимое папки, чтобы не получить лишний уровень `opentitan-zephyr-labs/opentitan-zephyr-labs/`.

## Следующие изменения

Небольшие готовые отчёты можно добавлять в `main`. Для незавершённого задания удобно создать ветку `lab/02-short-name`, а после проверки объединить её через pull request.

## Перед публикацией

Уберите из текста и скриншотов пароли, токены и другие личные данные. Сторонний код и материалы добавляйте с указанием источника и с соблюдением их лицензий.

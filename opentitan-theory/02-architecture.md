# 02. Архитектура OpenTitan Earlgrey

**Earlgrey** — одна из аппаратных конфигураций OpenTitan. Она включает процессорное ядро **Ibex** (RISC-V), память, интерфейсы ввода-вывода и специализированные аппаратные блоки безопасности.

## Основные элементы

| Блок | Назначение |
| --- | --- |
| Ibex | Исполнение программного кода RISC-V |
| ROM / память | Хранение кода начальной загрузки и данных в зависимости от типа памяти |
| UART / GPIO / SPI / I²C | Связь с внешними компонентами |
| Crypto accelerators | Аппаратное выполнение поддерживаемых криптографических операций |
| Key Manager | Управление производными ключами и ключевыми состояниями |
| Alert Handler | Обработка и маршрутизация сигналов об ошибках безопасности |

Архитектурная схема и точный набор блоков зависят от ревизии и конфигурации. Не переносите адреса и регистры между версиями без сверки.

**Источник:** [OpenTitan Hardware](https://opentitan.org/book/hw/).

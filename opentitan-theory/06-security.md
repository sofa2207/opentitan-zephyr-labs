# 06. Безопасность OpenTitan

OpenTitan проектируется с акцентом на аппаратную основу доверия. Среди ключевых направлений — доверенная загрузка, управление жизненным циклом, работа с ключами и аппаратная обработка ошибок.

## Важные различия

- **Генерация тестовых байтов** не равна криптографически стойкой генерации ключа.
- **Наличие криптоускорителя** не означает автоматическую доступность соответствующего API из RTOS.
- **Успешный обмен по UART** подтверждает работу протокола, но сам по себе не доказывает безопасность приложения.

В лабораторной № 03 при выполненной симуляции использовался тестовый RNG после ошибки PSA Crypto `-148`; полученные данные **не следует считать криптографически стойкими ключами**.

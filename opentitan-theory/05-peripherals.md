# 05. Периферия OpenTitan

Периферия обеспечивает обмен между программой и внешним миром.

| Интерфейс | Типичное назначение |
| --- | --- |
| UART | Последовательный текстовый обмен и диагностические сообщения |
| GPIO | Дискретные входы и выходы |
| SPI | Синхронный обмен с внешними устройствами |
| I²C | Двухпроводная шина обмена |
| Таймеры | Отсчёт интервалов, события и прерывания |

## UART в лабораторных

В работах по Zephyr UART используется как канал для команд и ответов. Протокол приложения (например, `STATUS` и `EXIT`) — это **логика лабораторной работы**, а не аппаратные команды UART.

См. [UART echo](../opentitan-zephyr/labs/02-uart-echo/) и [UART status](../opentitan-zephyr/labs/04-uart-status/).

**Источник:** [OpenTitan IP](https://opentitan.org/book/hw/ip/).
